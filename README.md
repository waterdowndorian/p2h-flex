# P2H 유연화 시스템 | P2H Flex Lab

GitHub Pages에 올릴 수 있는 정적 웹사이트입니다. 별도의 서버, 설치, 빌드 명령 또는 API 키가 필요하지 않습니다.

## 배포하기

1. P2H 시스템 전용 저장소를 준비합니다. 기존 다른 사이트의 저장소에 덮어쓰지 마세요.
2. ZIP의 압축을 풀고 내용물 전체를 `main` 브랜치의 루트에 올립니다. `index.html`과 `assets/`가 같은 단계에 보이도록 하고, 숨김 파일인 `.nojekyll`도 같이 올립니다. ZIP 자체만 올리면 웹사이트가 표시되지 않습니다.
3. GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택합니다. 브랜치는 `main`, 폴더는 `/(root)`를 선택하고 저장합니다.
4. 같은 설정 화면에 표시되는 사이트 주소를 엽니다. 일반 프로젝트 주소는 `https://<계정명>.github.io/<저장소명>/` 형식입니다. 모든 페이지와 리소스는 상대 경로라 저장소 하위 경로에서도 동작합니다.

[GitHub Pages 공식 설정 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## 공개 범위

- GitHub Pages는 일반 설정에서 공개 웹사이트입니다. 저장소를 비공개로 하더라도 사이트까지 비공개가 되는 것은 아닙니다. 로그인, 실증 현장 연동 및 실제 VPP 지령 기능은 없습니다.
- 공개용 예시 도면 두 장과 모의 데이터만 기본으로 포함했습니다. 기존 비공개 버전의 현장 도면·사진 및 첨부 요금 참고 이미지는 포함하지 않았습니다.
- **측정데이터 처리**에서 CSV를 선택하면 브라우저 메모리에서 분석합니다. 서버로 전송하거나 영구 저장하지 않습니다. **현장측정**의 두 예시 도면을 클릭해 교체한 파일은 그 사이트 주소와 브라우저에만 저장되고 다른 방문자에게 공유되지 않습니다. 기존 비공개 사이트에서 저장한 도면이 새 주소로 자동 이전되지는 않습니다.

## 확인하기

- **현장측정:** 운전 시나리오, 계측점 및 구성도 넘기기
- **효율측정(M&V):** 설비별 지표와 모의 비교기간
- **수요유연화(DR/VPP):** 모의 응동, 요금·제어 권고, VPP 구성
- **측정데이터 처리:** 예시 데이터 또는 CSV로 일별 추이, 시간대별 분포, 측정값 표 확인
